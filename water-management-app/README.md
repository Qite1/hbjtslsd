# 水利工程质量安全合规管理助手（Web）

面向水利施工企业的质量安全合规管理平台，天蓝色水利工程设计风格。前端为**纯静态单页应用**（HTML/CSS/JS），无需构建、无需后端，数据保存在浏览器本地（`localStorage`），可直接打开、可一键发布到任意静态站点/Nginx。

---

## 一、功能总览

| 模块 | 说明 |
|---|---|
| 🏠 首页 | 湖北建投水利水电工程有限公司介绍（公司概况 / 业务领域 / 技术力量 / 安全质量体系 / 企业文化）＋ **在建项目简介** ＋ 问题及整改情况预览（统计卡片＋最近问题预览卡片，点击跳转整改台账）＋ 整改闭合进度条 |
| 🔐 登录 | 账号密码登录，识别 **管理员 / 审核员 / 施工员** 三种身份 |
| 📸 上传隐患（施工员 / 审核员 / 管理员） | 上传现场照片（可多选、自动压缩），调用 AI 图像识别接口，依据水利工程安全、质量技术规范自动识别隐患并生成整改意见；AI 把握不足的项标记为**「需现场核实」**，由提交人现场确认后提交 |
| 📤 待审核（审核员） | 审核施工员提交的问题，可确认入台账、修改整改意见 |
| 📋 整改台账 | 记录问题 → 审核确认 → 开始整改 → 已整改 → 销号的完整闭环；施工员据此落实整改 |
| 👥 用户管理（管理员） | 新增用户、为用户赋予/调整「管理员 / 审核员 / 施工员」身份 |
| 📖 规范查询 | 提供 30+ 部水利工程规范与法规，按「质量·验收 / 施工技术 / 安全 / 通用·技术 / 法律法规」分类；每条规范链接到权威平台（全国标准信息公共服务平台、国家法律法规数据库等）的检索结果页，点击即可在线查询该规范 |
| 🤖 AI 接口（管理员） | 配置在线视觉模型接口地址 / 模型 / API Key |

### 权限矩阵
- **管理员**：拥有本网页的**全部功能权限**（上传隐患、审核、整改台账、用户管理、AI 接口）。
- **审核员**：可上传照片审核、查看并处理待审核、编辑整改台账。
- **施工员**：上传现场照片、提交问题、落实整改，并删除其提交的问题。
- **删除问题**：施工员、审核员、管理员均可删除问题记录。
- **编辑整改台账（删除、修改、状态调整等）**：审核员与管理员。

## 二、AI 隐患识别接口

系统按 **OpenAI 兼容 `/chat/completions` 视觉请求** 调用接口：

- **默认已预填 API Key**：`sk-b253b08c86e14822bd521bad4a360093`
- **默认接口地址**：`https://api.openai.com/v1`，默认模型 `gpt-4o-mini`
  - ⚠️ 若你的服务是第三方中转，请在登录管理员后进入 **「AI 接口」** 页面，将 **BaseURL** 改为对应服务地址（如 `https://你的中转域名/v1`），并视需要调整模型（需支持图片输入）。
- 请求会携带 `Authorization: Bearer <apikey>`，要求模型按水利工程安全质量规范输出 **JSON**，包含：隐患标题 / 描述与规范依据 / 风险等级 / 规范条款 / 整改措施 / 是否需现场核实。
- 接口不可用（未配置、网络失败、返回异常）时，系统**自动回退到本地规则识别**并标记「需现场核实」，保证应用离线也能演示完整闭环。

## 五、部署发布

本目录为**纯静态成品**，将其整体发布到任意 Web 服务器即可：

1. 目录拷贝到 Nginx 静态根目录（或任意静态托管），URL 指向 `index.html`。
2. 使用 UWork 试用服务器一键发布（见 `uwork-publish` 技能），应用名建议 `water-quality-safety`：
   ```bash
   ssh -i <keyPath> -p <port> <user>@<host> "mkdir -p <appsRoot>/water-quality-safety"
   scp -i <keyPath> -p <port> -r water-management-app/. <user>@<host>:<appsRoot>/water-quality-safety/
   ```
3. 访问 `http://<publicDomain>/water-quality-safety/`。
4. 更新：改完再次发布即覆盖；下线：联系管理员删除该目录。
